## 正文实时因果

- `+1`：首次轻中度越界/欺骗/物化，或首次取得一项新的不当主角红利。
- `+2`：严重或重复越界、利用弱势/依赖、重大欺骗背叛、明确拒绝后继续。
- `+3`：明知故犯严重伤害、权力压迫、借特权逃避重大责任。
- `+5`：极少数重大因果断裂或系统性剥夺选择权。
- `-1/-2/-3`：真实克制与小修正 / 承担现实成本并恢复边界 / 长期偿还并拆除耐久债源。
- 单纯受苦、受伤、死亡不降低因果。
- `OLD01` 仍是条件触发一次性 `+20`。

## 正文实时世界纠正

仅在 `CORR_ACTIVE=1` 后结算：

- `+1`：单个人边界、拒绝权、独立选择、相称后果真正生效。
- `+2`：耐久关系/规则被修正，错误红利撤回，对等成本补足。
- `+3`：制度性、多角色秩序修复，长期主角特权稳定拆除。
- `+5`：人神、命运、转生逃责、叙事兜底等世界级机制被实际约束。
- 对应回退可 `-1/-2/-3/-5`。
- 世界纠正不是因果镜像；自由知情地选择鲁迪，不因“仍选择鲁迪”本身扣纠正。

## 防双算与时间跳跃

- 已带 `[因果:*]` 的原作事件：结算固定标签，不再对同一行为追加通用正文因果。
- 已带 `[纠正:CORR-*]` 的固定锚点：不再对同一纠正重复实时加分。
- 只有超出原事件的新增行为/新增特权/新增结构变化才额外实时结算。
- 时间跳跃不按天数乘因果或纠正，只结算文本明确确认发生的事实。
- 两值统一执行 `MAX(0, MIN(100, 原值 + Δ))`。

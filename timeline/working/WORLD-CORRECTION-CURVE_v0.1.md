# 世界纠正度时间线曲线审计 v0.1

## 前提
- 本曲线只模拟“故事从第一卷开始，帝皇在T+3降临，随后原作事件基本照常发生”的固定时间线锚点。
- 不包含正文实时纠正，也不把帝皇主动改写世界后的新增纠正算进去。
- 不回填帝皇降临前已经发生的历史事件。

## 固定锚点总量
- 唯一 CORR 账目：25。
- 原作自然路线固定纠正总量：约 28。

## 解读
这正是预期结果：原作世界并非完全没有边界、反省和独立选择，因此不是0；但它也远没有系统性拆掉围绕鲁迪的主角特权，因此自然路线不应接近100。

真正把纠正度推向 40/60/80/100 的主力，应来自：
1. 魔改正文中阻断/偿还特权债；
2. 帝皇介入后建立稳定、公平且不以鲁迪为中心的新规则；
3. 角色在知情情况下重新获得拒绝、离开、选择与追责能力；
4. 人神、转生、命运兜底机制被识别并受约束。

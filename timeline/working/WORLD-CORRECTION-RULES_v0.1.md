# WORLD-CORRECTION-RULES v0.1

## 定义
世界纠正度衡量六面世界从“主角特权吞掉后果/人物围绕鲁迪失去自主性/错误缺乏代价”的状态，向“边界有效、选择独立、行为有后果、责任可追溯、神与命运不能无限兜底”的状态恢复了多少。

它不是“鲁迪受苦值”，也不是“鲁迪被讨厌值”。

## 区间
- 绝对区间：0～100。
- 强制公式：`MAX(0, MIN(100, 原纠正度 + 本回合Δ))`。
- 不允许历史事件倒灌：只有 {{user}} 本次故事 T+3 帝皇降临之后实际发生的纠正事件才结算。
- 同一 `CORR-*` ID 永久去重；动画摘要与小说卷重复同一事件只结算一次。

## 时间线固定锚点默认增量
- `+1`：局部边界被维护、人物做出独立选择、明确道歉/承担、真实社会后果出现。
- `+2`：结构性纠正：制度/权力滥用被处理、长期依附关系被拆开、旧世责任开始真正回收。
- `+3`：世界级纠正：神/命运/转生机制的异常兜底被实质限制或公开并建立稳定约束。

## 不加分
- 单纯受伤、失恋、挨打、死亡、贫困。
- 与错误行为没有因果关系的苦难。
- “有人终于不喜欢鲁迪”本身。
- 角色被强迫离开鲁迪、被帝皇替其做决定。

## 可减分
纠正度不是只升不降。若已经建立的边界/独立/公平规则被重新破坏，可 `-1/-2`；但“新增一笔因果债”本身不自动让纠正度下降，只有**已修复结构发生回退**才下降。

## 与因果的关系
同一事件可以同时：
- `因果 +1`：鲁迪仍享受了不当红利；
- `纠正 +1`：其中另一部分真实恢复了边界/承担。
两者不互相抵消。

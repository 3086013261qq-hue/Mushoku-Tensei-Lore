# KARMA-GLOBAL-RULES v0.1

## 总账
- 鲁迪总因果 = 行为因果 + 特权因果。
- 同一账目 ID 永久去重；摘要线与详细卷重复出现不得重复结算。
- 特权因果默认 P1=+1 / P2=+3 / P3=+5。
- 行为因果采用咩咩式离散增减：轻度±1、中度±3、重度±5；旧世回流另由条件事件触发。
- 一次事件多个特权标签按最高档结算一次；行为因果与特权因果可同时结算。

## 纠正
- “受苦”本身不增加世界纠正度。
- 错误红利被撤销、对等成本补足、受影响角色恢复真实拒绝权/独立选择，才可增加纠正度。
- 特权偿还不得自动抹除另行存在的行为因果。

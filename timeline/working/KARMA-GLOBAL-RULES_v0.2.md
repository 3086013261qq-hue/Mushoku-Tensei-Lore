# KARMA-GLOBAL-RULES v0.2

## 总账
- 鲁迪总因果 = 行为因果 + 特权因果 + 已释放的旧世回流。
- 显示范围 0～100；同一账目 ID 永久去重。
- 所有已确认特权都必须计债：首次取得统一 `+1`。
- `P1/P2/P3` 不再直接等于数值增量，而表示叙事特权的严重度、纠正优先级与后续表现强度。
- 行为因果：轻/中度 `+1`，重度或持续性明确越界 `+2`。
- 明确克制、承担、认错并实际修正：通常 `-1`；单纯受苦不减因果。
- 行为因果与特权因果可以在同一事件同时结算。

## 旧世因果回流 OLD01
- 前世底账保持冻结，不在开局灌入。
- `OLD01` 是一次性的条件债，触发时 `+20`。
- 只有发生与旧世核心恶行高度同质的重犯、或在真相暴露后仍明确拒绝承担时才释放。
- `T22` 负责暴露/确认旧世来源，本身不自动释放 `OLD01`。
- 一旦释放，账目 ID `OLD01` 永久去重。

## 显示阶段
- 0～19：潜伏。只记录，不强行制造明显惩罚。
- 20～39：裂纹。偶发不协调感、关系中的细小阻力开始出现。
- 40～59：渗出。旧世气质/叙事偏宠开始更容易被旁人察觉。
- 60～79：偏移。世界纠正明显介入，原本稳定的主角红利开始失灵或需要付出对等成本。
- 80～99：清算。通常需 `OLD01` 或重大后续重犯才能进入；帝皇可把鲁迪列为重点审判对象。
- 100：极限。不是“自动死亡按钮”，而是世界已无法继续无条件替其吞掉后果。

## 长期状态
- M09/M11/M20 等长期特权只在首次形成或明显升级时计 `+1`，普通调用不重复。
- 摘要线与详细卷重复同一账目 ID 时只结算一次。

## 世界纠正
- 世界纠正度与因果值分离。
- 错误红利被撤销、对等成本补足、受影响角色恢复真实拒绝权/独立选择，才增加纠正度。
- 特权偿还不能自动抹除另行存在的行为因果。

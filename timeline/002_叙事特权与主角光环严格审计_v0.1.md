# 叙事特权 / 主角光环严格审计 v0.1

> 阶段：严格候选审计，只打标签，不改母卡剧情正文。  
> 基线：《无职转生 - 沙盒》v5.3.0。  
> 原则：本轮刻意“宁可多抓，不要漏抓”；候选进入正式 working 时间线前仍需二次确认。

## 1. 为什么单独增加这一层

原有“因果值”只能处理鲁迪主动做出的越界、欺骗、背叛与逃责行为；但本项目还要识别另一类更隐蔽的问题：**鲁迪没有付出与收益相称的代价，却因为主角位置获得了普通角色很难得到的资源、宽容、爱情、身体、保命机会、身份跃迁或命运照顾。**

这类事件本身不一定意味着鲁迪“有罪”，因此不得机械增加因果值；它们应作为“叙事特权”独立标签，为世界纠正度、关系独立性和后续蝴蝶效应提供判断依据。

## 2. 标签体系

- `PRIV-BIRTH`：转生/出身/家庭资源等出生彩票。
- `PRIV-POWER`：异常天赋、魔力、魔眼、技术复利等能力红利。
- `PRIV-SOCIAL`：身份、名望、贵人、制度或机会异常倾斜。
- `PRIV-RESCUE`：本应付出致命/重大代价时被外力兜底或复活。
- `PRIV-ROMANCE`：爱慕、忠诚、婚恋关系的形成或长期保持明显快于/强于行为投入。
- `PRIV-BODY`：女性身体被作为安慰、疗愈、报恩、奖励、支付或情绪调节工具。
- `PRIV-FORGIVE`：行为已造成冒犯/伤害，但关系代价被异常压缩、快速原谅或直接转为更亲密关系。
- `PRIV-HAREM`：多个恋爱对象在低冲突、低代价条件下共同接受围绕鲁迪的关系结构。
- `PRIV-DESTINY`：救世主、命运、神兽、预言等直接服务鲁迪/鲁迪家族的命运偏置。
- `PRIV-META`：人神、未来信息、超常情报等给鲁迪提供常人无法取得的攻略视角；若同时有操纵与代价则标记“混合”。

### 严重度

- `P1`：轻度/可解释；有现实原因，但明显带有主角便利。
- `P2`：清晰叙事偏爱；收益与投入/代价存在明显不对称。
- `P3`：强主角光环；改变命运、关系或生死，且普通角色几乎不可能得到同等待遇。

**重要：`P1~P3`不是因果值。** 它描述“世界给了鲁迪多少额外便利”，不是“鲁迪有多坏”。

## 4. 必须保留的反例：不是所有好事都算主角光环

为了避免系统变成“只要鲁迪得到好处就判罪”，以下类型只做对照，不自动打高等级标签：

- 艾莉丝在第二卷对偷袭内裤、越界摸腿直接痛打鲁迪：真实即时后果。
- 莎拉在第七卷听到鲁迪羞辱自己后扇耳光并决裂：真实关系后果。
- 安洁在第十八卷看到“圣物内裤”行为后爱意当场破灭：叙事特权撤销的优良样本。

## 5. working 时间线建议写法

后续不要塞大段评论，只给关键事件加短标签，例如：

`[因果:边界侵犯+3][特权:FORGIVE/P3][旧世共鸣:否]`

或：

`[因果:+0][特权:BODY+HAREM/P3][纠正候选:是]`

其中：
- `因果`只记录鲁迪自己的选择。
- `特权`记录世界/其他人物给他的异常便利。
- `纠正候选`表示蝴蝶效应中如果该便利被取消、变成需要真正争取的关系或产生正常后果，世界纠正度可以上升。

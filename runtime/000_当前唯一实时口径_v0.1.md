# 当前唯一实时口径 v0.1

## 1. 数据源
- 固定历史/原作节点：读取 `karma-ledger.v0.2.json` 与 `world-correction-ledger.v0.1.json` 已写入时间线的机器标签。
- 正文新增行为：由每回合 `<causality>` 实时判断。
- 咩咩兼容：占用母卡原本未使用的 `affinity_format` 槽；不修改咩咩预设，不建立第二套数据库。

## 2. 初始化
- 每条启用时间线顶部写入 `RUNTIME_BASELINE`。
- 鲁迪因果初值 = 该时间线 `KARMA_BASE` + 当前卷中严格早于随机开局点、且已经发生的数值因果标签。
- 世界纠正初值 = 0。
- 帝皇 T+3 降临前 `CORR_ACTIVE=0`，历史纠正不倒灌。

## 3. 正文实时因果
- +0：中性/只有念头/同一原作标签已完整结算。
- +1：首次轻中度越界/欺骗/物化；或新获得一项不当主角红利。
- +2：严重或重复越界、利用弱势/依赖、重大欺骗背叛、明确拒绝后继续。
- +3：明知故犯严重伤害、权力压迫、借特权逃避重大责任。
- +5：极少数重大因果断裂或系统性剥夺他人选择权。
- -1/-2/-3：分别对应真实克制与小修正、承担现实成本并恢复边界、长期偿还并拆除耐久债源。
- 受苦/受伤/死亡本身绝不减因果。

## 4. 正文实时世界纠正
- +1：单个人边界/拒绝权/独立选择/相称后果真正生效。
- +2：耐久关系或规则被修正、错误红利撤回、对等成本补足。
- +3：制度性/多角色秩序修复、长期主角特权稳定拆除。
- +5：人神、命运、转生逃责、叙事兜底等世界级机制被实际约束。
- 对应反转用 -1/-2/-3/-5。
- 自由知情地选择鲁迪，不因“仍选择鲁迪”本身扣纠正。

## 5. 防双算与继承
- 原作带机器标签的同一行为只结算标签；正文只计算超出原事件的新部分。
- 同一 `T/P/M/X/CORR` ID 永久去重。
- 每回合从上一条 `<causality>` 精确继承数值与 `KSET/CSET/OLD01/CORR_ACTIVE`。
- 时间跳跃不按天数乘因果/纠正，只结算明确发生的事实。
- 两值均执行 `MAX(0, MIN(100, 原值 + Δ))`。

## 6. 输出
输出位于咩咩原 `affinity` 槽：`<causality>...</causality>`。MVU 后续只读取这一个事实源。

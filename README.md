# Mushoku-Tensei-Lore

《无职转生 - 沙盒》授权二创资料库 / 角色卡魔改工程。

## 当前目标

以 SheepSheep 制作的《无职转生 - 沙盒》v5.3.0 授权母卡为唯一基础，在尽量保留原有世界观、人物、地点、时间线骨架与咩咩体系兼容性的前提下，进行局部剧情魔改与新增运行时系统。

当前核心改造范围仅限：

1. 时间线：加入第三日帝皇娘降临，并为关键伦理/因果事件补充可供后续运行时判定的语义标记。
2. 人物：新增女性化人类帝皇（黑皮、小只、母性、温柔、爱人类、刚正不阿），与 {{user}} 的具体关系不预设，可自然发展。
3. MVU：只负责鲁迪因果值、世界纠正度、鲁迪的一百种死亡方式、一键复活鲁迪。
4. 数值机制：优先复用咩咩预设成熟的好感度实时增减/继承/阈值拦截机制，不另造复杂状态系统。

## 基线原则

- 授权母卡原件永久只读，不直接覆盖。
- 所有二创修改从工作副本派生。
- 禁止无关重构成熟世界书、人物、地点和原作剧情骨架。
- 禁止把“鲁迪受罪”写成无条件即时惩罚；因果回流必须缓慢、可累积，并与实际选择对应。
- 世界纠正度衡量人格自主、因果秩序与制度修正，不等同于“鲁迪倒霉程度”。

> 本仓库只保存本项目授权范围内的二创工程资料与构建产物。

## 当前目标

以 SheepSheep 制作的《无职转生 - 沙盒》v5.3.0 授权母卡为唯一结构基础，在尽量保留原有世界观、人物、地点、时间线骨架与咩咩体系兼容性的前提下，进行增量装配：

1. 时间线：46/46 加入随机开局因果基线、固定因果标签、世界纠正锚点与第三日帝皇娘降临 Overlay。
2. 人物：新增女性化人类帝皇（黑肤、小只、母性、温柔、爱人类、刚正不阿）与12名娘化原体；不预设 {{user}} 与帝皇的具体关系。
3. MVU：鲁迪因果值、世界纠正度、死亡签、百死图鉴、一键复活、帝皇宣言/箴言与最终黑曜石法典视觉。
4. 数值机制：复用咩咩体系成熟实时继承/夹紧思路，不另造第二套伦理数据库。
5. 媒体：帝皇娘正式 WebP 与宣言 MP3 通过 GitHub → jsDelivr CDN 远程加载，不向卡体塞 Base64 大媒体。

## 基线原则

- 授权母卡原件永久只读，不直接覆盖。
- 所有二创修改从工作副本派生。
- 禁止无关重构成熟世界书、人物、地点和原作剧情骨架。
- 禁止把“鲁迪受罪/死亡”写成偿债；因果变化必须对应实际行为、责任与红利。
- 世界纠正度衡量人格自主、边界、因果秩序与制度修正，不等同于“鲁迪倒霉程度”。
- 同一回合无论跨过多少新5点阈值，最多只抽1种死亡方式。
- 正式组装不得修改用户咩咩预设，不得自制第二套 MVU 底层。

> 本仓库只保存本项目授权范围内的二创工程资料与构建产物。

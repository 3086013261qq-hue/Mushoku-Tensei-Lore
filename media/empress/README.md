# 帝皇娘正式视觉素材 v1

本目录只允许使用用户在当前项目中指定的 9 张正式帝皇娘图片。

## 唯一用途映射

| 文件 | 来源 | 用途 |
|---|---|---|
| `EMP-BASE-01.webp` | 第6张 | 唯一正式主立绘 |
| `EMP-LOCK-01.webp` | 第3张 | 首次/后续箴言锁屏圆章 |
| `EMP-QUOTE-01.webp` | 第8张 | 箴言栏侧影/轻量头像 |
| `EMP-REVIVE-01.webp` | 第9张 | 复活区半身陪衬；禁止裁出复杂手势 |
| `EMP-CODEX-01.webp` | 第4张 | 死亡法典/死亡签氛围主图 |
| `EMP-ALT-01.webp` | 第1张 | 备用：宿命感回眸 |
| `EMP-ALT-02.webp` | 第2张 | 备用：近景/头像 |
| `EMP-ALT-03.webp` | 第5张 | 备用：背影/法典插页 |
| `EMP-ALT-04.webp` | 第7张 | 备用：其他裁切 |

## 硬规则

- `EMP-BASE-01.webp` 是唯一正式主立绘。
- 禁止静静/后续施工自行搜索、生成或混入其他帝皇娘人物图。
- MVU人物装饰只能从本目录正式图库裁切。
- 死亡签优先取纹样/日轮/氛围，不重复堆完整人物。
- 复活区不得重新生成手部；若裁切涉及复杂手势，直接改为半身、袖口或光纹。
- ALT 文件仅为备用，不得擅自替换主立绘。

机器清单与 SHA256：`empress-assets-manifest.v1.json`。

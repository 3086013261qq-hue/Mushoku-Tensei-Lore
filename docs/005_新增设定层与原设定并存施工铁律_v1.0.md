# 《无职转生 - 沙盒 · 因果法典》
# 新增设定层与原设定并存施工铁律 v1.0

> 目的：消除“原41条核心设定逐字继承 = 不允许新增设定”的错误理解。
>
> 正确口径：**原设定保留，新设定追加；旧世界书不重写，新规则作为独立新增层进入派生 Candidate。**

## 1. 原有核心设定如何处理

授权母卡原有41条核心设定必须逐字继承，不允许为了适配本项目而重写、摘要、删改或合并。

这41条是母卡既有世界观基础，不是本项目新增规则的承载容器。

## 2. 本项目明确新增的设定/规则层

以下内容均属于《因果法典》二创新增设定，不属于母卡原41条核心设定：

### A. 鲁迪因果系统
- 鲁迪因果值 0~100；
- 固定时间线因果标签；
- 正文实时因果增减；
- 不当主角红利计入因果；
- OLD01 旧世回流一次性规则；
- KSET 去重；
- 因果阶段：潜伏 / 裂纹 / 渗出 / 偏移 / 清算 / 极限。

### B. 世界纠正系统
- 世界纠正值 0~100；
- T+3 帝皇降临后 CORR_ACTIVE=1；
- 边界/拒绝权/选择权/制度修正等计入纠正；
- CSET 去重；
- 世界纠正不是“惩罚值”或“鲁迪受苦值”；
- 阶段：萌芽 / 局部纠偏 / 结构松动 / 秩序重构 / 深层校正 / 高位稳态。

### C. 帝皇监察与因果秩序
- {{user}}故事 T+3 帝皇娘降临六面世界；
- 帝皇识别{{user}}为她已知的同一存在，但关系不预设；
- 帝皇负责观察、确认事实、恢复选择权、撤回错误红利、要求承担后果；
- 帝皇不是因果值高就立即处刑的自动惩罚器。

### D. 死亡签机制
- 帝皇监察激活后，因果或纠正首次向上跨新5点阈值时，本回合获得死亡抽取资格；
- 同一回合无论跨几个阈值，最多抽1种死法；
- 场景不合理时最多保留1个 pending_death_trigger；
- 不存在 death_queue；
- 死亡本身因果+0、纠正+0。

### E. 百死图鉴
- 固定100种死亡方式；
- 八类：魔法 / 战斗 / 旅行 / 日常 / 权谋 / 帝皇 / 因果 / 荒诞；
- 未发现词条不提前泄露名称；
- death_seen 只记录收藏状态，不反向改写剧情伦理。

### F. 一键复活
- 只恢复鲁迪生存状态；
- 不清空因果、世界纠正、关系、KSET/CSET、OLD01、图鉴、已跨阈值记录；
- 死亡与复活不能用于偿债。

### G. <causality> 实时事实源
- 复用咩咩原本未使用的 affinity_format 槽；
- 每回合输出本回合变动、当前因果、当前纠正、生死状态和RT机械信息；
- MVU只读取这一事实源，不重复伦理计算。

## 3. 新增设定的正确挂载方式

这些新增内容必须作为**独立新增世界书/运行时规则条目**挂入派生 Candidate。

正确结构：

`原41条核心设定（逐字继承）`
`+ 因果法典新增规则条目`
`+ 帝皇 Overlay / 新增人物`
`+ MVU / runtime 机械层`

禁止：
- 把因果值规则硬塞进某个原41设定并改写原文；
- 为了“统一”把原设定和新增设定合并成一条；
- 用新增设定替换原设定；
- 因为原设定不包含因果值，就判断“因果值不是正式设定”。

## 4. 角色与时间线的区别

### 原角色/原地点/原核心设定
默认0改写，逐字继承。

### 原46时间线
原文逐字继承，但允许按已批准映射插入机器标签、RUNTIME_BASELINE和必要机器注释。

### 新增人物
帝皇娘 + 十二原体娘，共13条，独立新增。

### 新增设定
因果、世界纠正、死亡签、百死图鉴、复活、帝皇监察等，均独立新增。

因此“原文继承”与“新增设定”完全不冲突。

## 5. Candidate QA

Candidate1 必须同时满足：

- 原41核心设定仍完整存在且正文不变；
- 新增因果/纠正/死亡/复活/帝皇监察规则条目存在；
- 原设定条目数不因新增规则而减少；
- 新增条目不能覆盖原entry；
- MVU读取的规则必须能追溯到当前新增设定/runtime文件；
- 不得出现“为了适配因果系统而重写原世界观”的改动。

## 6. 一句话施工原则

**原设定保留，因果法典追加。**

不是“只继承原卡、不加新设定”，也不是“为了加新设定去改旧设定”。

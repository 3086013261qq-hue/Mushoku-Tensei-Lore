## 2. 因果法典新增设定层

以下均属于独立新增设定/规则，而不是对原41条的改写：

### A. 鲁迪因果系统
- 因果值0~100；
- 固定时间线标签 + 正文实时增减；
- 不当主角红利计入因果；
- KSET去重；
- 阶段：潜伏 / 裂纹 / 渗出 / 偏移 / 清算 / 极限。

### B. 世界纠正系统
- 世界纠正0~100；
- T+3帝皇降临后CORR_ACTIVE=1；
- 边界、拒绝权、选择权、制度修复等计入纠正；
- CSET去重；
- 纠正不是“鲁迪受苦值”；
- 阶段：萌芽 / 局部纠偏 / 结构松动 / 秩序重构 / 深层校正 / 高位稳态。

### C. 帝皇监察
- {{user}}故事T+3帝皇娘降临；
- 帝皇确认事实、恢复选择权、撤回错误红利、要求承担后果；
- 因果高不等于自动处刑。

### D. 死亡签 / 百死图鉴 / 一键复活
- 帝皇监察激活后，因果或纠正首次跨新5点阈值时获得当回合死亡抽取资格；
- 同回合无论跨几个阈值最多抽1种死法；
- 最多保留1个pending，不存在death_queue；
- 死亡/复活本身因果+0、纠正+0；
- 复活不清账、不读档。

### E. `<causality>`实时事实源
- 复用咩咩预设affinity_format槽；
- 每回合输出因果、纠正、生死和RT机械字段；
- MVU只读该事实源，不重复伦理计算。

### F. 因果显相·前世恶相回流
- 因果越高，他人视觉越接近鲁迪前世那个肥胖臃肿、油乱邋遢、萎靡且神情猥琐的成年男人旧貌；
- 不是灵魂形象，也不改变现世物理身体；
- 因果降低时按当前阶段减弱。

### G. 世界纠正·主角偏爱退潮
- 纠正越高，世界越撤回鲁迪无代价的主角光环、巧合兜底、关系便利和命运偏爱；
- 不是反鲁迪诅咒，不制造无因坏运气；
- 真实能力、真实付出和自由选择得到的好结果仍有效。

### H. 因果法典·旧世因果回流
- 正式定义OLD01；
- 明确机器锚点或沙盒中的严重同源重演才可触发；
- 念头/梦境/闪回/坦白本身不额外收费；
- 首次触发+20，随后`OLD01=1`永久去重。

### I. 因果法典·历史不可逆与沙盒分歧
- 因果/纠正/死亡签/复活不自带时间回滚；
- 世界纠正改未来，不retcon过去；
- 沙盒真实行动可偏离母卡未来轨道；
- 未实际发生的未来事件不结算标签；
- 复活只恢复生存状态，不是读档。

### J. 因果法典·人物自主与关系自由
- 纠正只恢复选择条件，不指定感情结果；
- 可以离开、原谅、和解或继续选择鲁迪；
- {{user}}不能自动继承鲁迪失去的爱情/资源/主角红利；
- 帝皇娘不能替任何人物决定爱谁。

### K. 十二原体娘·跨界登场边界
- T+3唯一固定跨界者仍是帝皇娘；
- 十二原体只是可登场角色池，必须有正文跨界原因才实体登场；
- 禁止无铺垫十二人集体空降；
- 保留各自立场、姐妹矛盾和历史；
- II/XI与未收录原体不自动补造。

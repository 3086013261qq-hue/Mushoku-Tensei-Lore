## 二、允许修改范围

### 1. 时间线
- 保留原作卷级骨架与主要事件顺序。
- 对涉及鲁迪伦理责任、边界侵犯、关系背叛、责任逃避、旧世恶行共鸣等关键节点补充机器可判定语义。
- 新增“第三日：帝皇娘降临六面世界”这一核心分歧点。
- 时间线仅提供事实与判定锚点，不强制蝴蝶效应后的剧情必须回到原作。

### 2. 人物
新增女性化人类帝皇：
- 战锤世界的人类帝皇本人之女性化表现。
- 黑皮、小只、母性、温柔、真诚地爱人类。
- 刚正不阿，对责任、秩序、人格尊严和异端审判有清晰原则。
- 来到六面世界的主要目的为观察、纠正秩序并处理异常与异端。
- 她认识 {{user}}；但 {{user}} 的身份、来历与二人既有关系不替玩家预设。
- 二人可以自然发展成恋人，但绝不强制绑定。

### 3. MVU
正式职责仅限：
- 鲁迪因果值。
- 世界纠正度。
- “鲁迪的一百种死亡方式”词条收藏。
- “一键复活鲁迪”。

MVU不得接管主线导演，不得复制第二套世界状态数据库，不得把所有角色关系塞进面板。

### 4. 数值机制
实时数值优先复用咩咩预设成熟的好感度机制：
- 本回合判定 → Δ → 继承旧值 → 阈值拦截 → 输出新值。
- 禁止另造臃肿数据库与复杂状态机。
- 因果值与世界纠正度均采用可控区间和明确增减映射。

## 三、核心叙事原则

1. **转生不是赦免。** 新人生不能自动抹消旧日责任。
2. **鲁迪不会第三天立刻崩溃。** 因果影响必须缓慢、累积、与实际行为对应。
3. **苦难不等于因果清算。** 只有由其行为引发的社会、关系、心理或命运后果才属于有效清算。
4. **帝皇不是泄愤处刑器。** 她的目标是恢复秩序，而非无条件折磨某个人。
5. **女性角色不是奖品。** 世界纠正后，她们拥有重新判断、继续爱、离开、拒绝或选择其他人生的完整自主权。
6. **世界纠正度不等于鲁迪倒霉程度。** 它衡量人格自主、因果秩序与制度修正。
7. **死亡不洗债。** 一键复活仅恢复存活状态，不清空因果、关系、纠正度或死亡图鉴。

- 禁止把所有原作事件改成“鲁迪受罚事件”。
- 禁止把帝皇写成只会喊异端并秒杀一切的单一角色。
- 禁止把希露菲、洛琪希、艾莉丝等人简单改造成围着 {{user}} 转的新奖品。
- 禁止为了因果系统而破坏咩咩预设已有的稳定数值增减逻辑。

# mvu

当前设计阶段只做 **视觉方案 + 交互规则**；正式装配、实机回归和最终打包留给后续施工。

本项目 MVU 坚持轻量化，只负责：

1. 展示鲁迪因果值。
2. 展示世界纠正度。
3. 展示/收藏“鲁迪的一百种死亡方式”。
4. 提供“一键复活鲁迪”。
5. 提供一次性首次载入宣言锁屏与后续帝皇箴言锁屏。
6. 提供轻量“死亡抽取黑金签”视觉反馈。

## 唯一事实源
MVU只读每回合 `<causality>...</causality>` 中的因果、纠正、生死与RT状态；不得保存因果/纠正副本，也不得重新计算正文伦理或时间线账目。

## 宣言锁屏字幕

- 下一句不预显；
- 关键句允许单独居中放大约1.12倍；
- 关键句：`不会。` / `因果。` / `我是人类帝皇。` / `让这个世界重新学会因果。`

140.042s之后进入尾奏态：不再显示新字幕，只保留帝皇金环与六面纹；最后约6秒浮现第一条箴言并收束成普通箴言锁屏。

## 20格三态

- `历史基线格`：帝皇激活前已经存在的因果，仅低亮显示，不触发死亡抽取动画。
- `监察后已跨格`：正常亮起。
- `本回合新跨格`：短闪一次。

25 / 50 / 75 / 100 四个主刻度略高并带古金刻点；这只是视觉分区，不改变“每5点都是阈值”的业务规则。

## 死亡抽取机制 · 当前唯一口径
自帝皇T+3监察激活后：

- 因果值每首次向上跨过新的5点阈值，可触发本回合死亡抽取资格。
- 世界纠正每首次向上跨过新的5点阈值，也可触发本回合死亡抽取资格。
- **同一回合无论跨过几个新阈值，最多只随机抽取1种死亡方式。**
- 多余阈值仍登记为已跨过，但不排队、不补抽、不在后续回合追回。
- 同一阈值只触发一次；数值下降后重新升回，不重复刷。
- 随机开局时，帝皇激活前已经跨过的历史因果阈值只作为基线，不追溯死亡。
- 因果触发代表“债务收账”；纠正触发代表“主角光环/叙事兜底被拆掉后，正常世界风险重新生效”。
- 死亡与复活本身都不改变因果和世界纠正。
- 若当前场景没有合理死法，只允许保留1个 `pending_death_trigger`；pending存在时不再累积新的死亡抽取。

完整规则：`002_死亡签触发机制_v0.2.md`。

### 死亡抽取视觉 · v0.5

触发时固定顺序：

`新跨阈值格短亮 → 黑金签背面出现 → 单次翻面 → 显示分类与死法 → 百死图鉴同步点亮 → 收束成轻量短签`

同回合多阈值：

- 所有新跨格都可以短亮；
- 只允许一张死亡签翻面；
- 文案：`⚖ + 🌍 多重阈值 · 本回合仅抽取一次`；
- 不显示死亡队列。

场景不适配：

- 抽中的死法立刻锁定；
- 卡面显示 `死法已锁定 · 等待合理场景`；
- 后续进入合理场景时直接结算既有死法；
- 禁止重新随机、禁止再次翻签。

翻面完成后常驻短签示例：

`💀 本回合死法 · 主角光环断电`

完整视觉规范：`010_死亡抽取黑金签翻面视觉规范_v0.1.md`。

## 一键复活

- 鲁迪存活时禁用。
- 鲁迪死亡时可点。
- 复活只恢复生存状态，不清空因果、世界纠正、关系、KSET/CSET、OLD01、死亡图鉴或已跨阈值记录。
- 同一回合复活后不得再次触发第二次死亡抽取。

死亡态主文案：

`♻ 起来，账还没清。`

## 禁止事项

- MVU接管主线剧情导演。
- 再造第二套复杂数据库。
- 死亡本身当作还债/纠正。
- 复活清空既有债务或关系。
- 同一回合因为跨多个5点阈值连续抽取多个死法。
- pending死亡签重新随机或重新翻面。
- 每个新聊天/第一楼自动重播开机宣言。
- 宣言锁屏/音频偏好写入 `<causality>`。
- 当前设计阶段继续做正式装配、打包或实机施工。

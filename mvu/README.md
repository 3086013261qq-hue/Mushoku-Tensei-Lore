# mvu

本项目 MVU 坚持轻量化，只负责四件事：

1. 鲁迪因果值。
2. 世界纠正度。
3. 鲁迪的一百种死亡方式（仅词条收藏，不展开详细死亡描写）。
4. 一键复活鲁迪。

## 当前唯一数据源

从 working `v0.4` 起，MVU **只读取每回合输出的 `<causality>...</causality>`**：

- `⚖️鲁迪因果`
- `🌍世界纠正`
- 隐藏 RT 字段中的 `KSET / CSET / OLD01 / CORR_ACTIVE`

实时计算复用咩咩预设成熟的 `affinity_format` 输出槽：本回合判定 → Δ → 继承旧值 → 0～100 阈值拦截 → 输出新值。

禁止 MVU 自行重新计算时间线标签或正文伦理判断；MVU 是展示/交互层，不是真相源。

禁止：
- MVU 接管主线剧情导演。
- 再造第二套复杂数据库。
- 同时从时间线标签和 `<causality>` 重复累计数值。
- 复活时清空因果、关系、纠正度或死亡图鉴。

后续视觉施工必须建立在 `runtime/000_当前唯一实时口径_v0.1.md` 与 working v0.4 之上。

# 首次载入开机宣言与回听机制 v0.2

## 核心定位
本项目不再使用“第一楼自动播放视频”的口径。

正式设计改为：

**这张卡在当前设备/客户端上第一次真正载入时，自动进入一次“开机宣言”流程。**

该流程使用用户选定的视频 MP4。视频音轨核心为“人类联邦宣言”，例如用户描述的开头：

> 承认吧，根本无法忍受那些奇形怪状的异星人……

这里仅记录“音轨性质/氛围定位”，不在设计文档中全文抄录外部视频台词。

## 为什么这样更适合本卡
- 它不是普通 Opening，而是“第一次启动因果法典”的世界观宣告。
- 强仪式感只发生一次，不会每楼重复消耗审美。
- 后续因果法典保持克制、安静，让真正的正文承担叙事。
- 宣言强调人类立场、秩序、排斥异质风险的强烈意志；本卡自身的“纠错/因果/选择负责”价值观则由后续帝皇箴言和规则层继续完成。

## 首次载入判定
首次载入与“第一楼”完全分离。

推荐仅保存一个 UI 偏好标记：

- `opening_ever_seen: boolean`

判定：

1. 当前设备第一次载入此卡，`opening_ever_seen=false`：进入开机宣言。
2. 视频播放完成、用户跳过、或用户主动关闭：写为 `true`。
3. 以后无论：
   - 新开聊天；
   - 回到第一楼；
   - 切换时间线；
   - 关闭再打开 SillyTavern；
   - 页面刷新；
   都不得再次自动播放。
4. 只有用户主动点击 `回听宣言`，才重新播放。

该标记属于 UI 本地偏好，不影响剧情事实、因果、纠正、死亡抽取或世界书。

## 版本更新时的口径
默认不因为卡的小版本更新而重置 `opening_ever_seen`。

只有未来明确制作了“全新开机宣言”且用户希望重新体验时，才允许换一个版本化 key，例如：

- `opening_seen_manifest_v1`
- `opening_seen_manifest_v2`

禁止每次更新卡版本都强制重播。

## 正式视频
用户当前选定参考：

- 正式施工时由用户自行将允许使用的 MP4 上传到项目媒体仓库。
- 运行时继续使用既有 GitHub → CDN 云端媒体技术。

- `media/opening/federation-declaration-poster.webp`

卡体只保存远程 URL，不内嵌 Base64/大视频。

## 播放体验
### 首次载入
- 进入卡后，先出现全屏/大幅开机层，而不是直接显示完整 MVU。
- 视频保持原始画面比例，优先 16:9；手机端允许 letterbox，不强行裁关键内容。
- 背景使用黑曜石黑，不做额外粒子。
- 左上小字：`CAUSAL CODEX / FIRST BOOT`。
- 右上：`跳过`。
- 底部只保留极淡提示：`首次载入宣言 · 之后可在法典中回听`。

### 视频结束
视频结束后：
1. 画面黑场 0.4~0.8 秒；
2. 六面世界金纹淡入；
3. 出现一句帝皇原创箴言；
4. 法典主体从下方/淡入进入。

推荐第一句：

`世界允许第二次选择，但不替任何人删除第一次。`

## 声音策略
用户希望第一次载入时“自动播放完整 MP4（含声音）”。

正式设计口径：
- 优先尝试有声自动播放。
- 但 Android WebView / 浏览器可能阻止无用户手势的有声 autoplay。
- 若有声 autoplay 被阻止：
  - 不把失败当成开屏完成；
  - 保持首帧/海报；
  - 中央显示唯一主按钮：`播放宣言`；
  - 用户点击后从 0 秒有声播放。
- 不应偷偷改成静音播完后直接标记已看，否则会失去这段音轨的核心意义。

因此“有声优先，受平台限制时一键开始”优先于“为了自动成功而静音播放”。

## 后续回听
后续法典顶部/设置区保留一个很小的入口：

`◉ 回听宣言`

点击后：
- 临时展开同一视频播放器；
- 默认有声，从0秒开始；
- 播放完自动收回；
- 可手动关闭；
- 不改变 `opening_ever_seen`；
- 不影响当前楼层/剧情推进。

该入口只负责“回听/重看”，不允许自动触发。

## 后续普通状态
开机宣言看过以后，所有正常楼层只显示：

- 因果法典；
- 双进度；
- 百死图鉴；
- 一键复活；
- 一条帝皇箴言。

不再预留大面积视频区。

## 帝皇箴言的角色
宣言音轨与帝皇箴言承担不同职责：

- **人类联邦宣言**：第一次启动时的强烈阵营/文明/意志宣告。
- **帝皇箴言**：后续关于责任、选择、边界、宽恕与因果的温和校准。

两者不要混写成同一种声音。

尤其不得因为视频音轨带有强烈对异星生命的排斥语气，就把帝皇娘长期写成“见异族就杀/以愤怒代替判断”的单线角色。

## 后续箴言示例
- 世界允许第二次选择，但不替任何人删除第一次。
- 爱不是免罪券，痛苦也不是偿债凭证。
- 真正的自由，从来包含拒绝你的自由。
- 你可以被爱，但没有任何人天生属于你。
- 我爱人类，所以我不会把人类当成永远无需负责的孩子。
- 复活让你继续活，不让你的账自动归零。

## 允许的 UI 偏好
- `opening_ever_seen`
- `opening_manifest_version`
- `opening_volume`（可选，仅UI偏好）

禁止把这些字段写进因果/纠正真相源。

## 禁止
- 每个新聊天都自动重播。
- 每次回第一楼都自动重播。
- 每楼自动重播。
- 静音播放完就默认当用户已经体验过宣言。
- 视频加载失败阻塞卡片主体。
- 把外部视频台词直接当成无职世界的历史事实。
- 让视频的排外高燃语气覆盖帝皇娘已经锁定的“爱人类但要求承担责任、尊重个体选择”的人格核心。

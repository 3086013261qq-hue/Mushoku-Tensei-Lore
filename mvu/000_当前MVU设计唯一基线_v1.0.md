## 五、因果 / 世界纠正双20格

两条均固定为20格：

`每格 = 5点`

三态：
- 历史基线格：低亮；
- 监察后已跨格：正常亮；
- 本回合新跨格：短闪一次。

运行时阶段名称必须沿用既有规则：

因果：
`潜伏 / 裂纹 / 渗出 / 偏移 / 清算 / 极限`

世界纠正：
`萌芽 / 局部纠偏 / 结构松动 / 秩序重构 / 深层校正 / 高位稳态`

禁止视觉层另造阶段名。

唯一口径：

## 十、帝皇娘三种存在强度

### QUIET
- 顶栏金印40%；
- 箴言圆章存在；
- 其他人物纹理极淡；
- 无动画。

### OBSERVE
- 因果 / 纠正变化或死亡签翻面；
- 金印短升到60~70%；
- 法典暗纹短升；
- 约350ms恢复。

### INTERVENE
- 首次宣言 / 回听 / 复活；
- 锁屏图或复活半身明显出现；
- 日轮短暂完整；
- 随后恢复 QUIET。

无第四种持续高亮模式。

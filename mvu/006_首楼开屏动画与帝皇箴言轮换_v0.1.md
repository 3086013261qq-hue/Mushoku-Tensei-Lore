# 首楼开屏动画与帝皇箴言轮换 v0.1

## 目标
首楼提供一次强仪式感的“帝皇降临/因果法典启封”视频开屏；后续楼层默认回到轻量法典，只显示帝皇箴言，避免审美疲劳和移动端负担。

## 默认行为
1. 第一次进入本次故事的第一楼：显示开屏视频层。
2. 视频层结束或用户主动关闭后，进入正式因果法典。
3. 第二楼及以后：不再自动播放视频，只显示一条帝皇箴言。
4. 用户可以在法典右上角设置：
   - `首楼一次`（默认）
   - `以后只显示箴言`
   - `手动重播开屏`
5. 不提供“每楼自动播放”模式。

## Android / SillyTavern 音频策略
- 首楼视频允许自动尝试播放，但默认 `muted + playsinline`，保证移动端成功率。
- 视频中央覆盖轻按钮：`点亮声音`。用户点击后从0秒重新播放并解除静音。
- 若浏览器/酒馆已经允许有声播放，可直接在用户点击开屏后有声播放。
- 视频加载失败时不得阻塞MVU：直接落到箴言卡 + 因果法典。

## 云端媒体
用户可将正式MP4上传到项目媒体仓库，再由正式施工采用现有 GitHub → CDN 远程加载方案。
建议资源结构：
- `media/opening/opening-main.mp4`
- `media/opening/opening-poster.webp`
- 可选 `media/opening/opening-alt.mp4`

MVU只保存远程URL，不把MP4/Base64塞进卡体。

## 开屏布局
- 背景：全宽16:9视频，最大高度约240px，圆角裁切。
- 上层：极淡六面世界魔法纹 + 帝皇金环，禁止遮挡主体。
- 左上：`CAUSAL CODEX · PROLOGUE`
- 右上：`跳过`。
- 视频结束前1.5秒，黑金渐暗并出现一句原创箴言，然后顺滑收进法典顶部。
- 不做大面积粒子，不循环播放。

## 结束箴言
默认候选：
`世界允许第二次选择，但不替任何人删除第一次。`

可选：
`选择可以重来，代价不会因此消失。`

## 后续楼层箴言模式
第二楼起，视频区域缩成高度约42~58px的“法典铭文条”。
- 左侧：小型帝皇金印/剪影。
- 中间：一句箴言。
- 右侧：极小的 `重播开屏` 图标按钮。

箴言建议用稳定轮换，不因刷新重抽：按消息ID/楼层序号映射固定一句。

### 原创帝皇箴言池 v0.1
1. 世界允许第二次选择，但不替任何人删除第一次。
2. 宽恕不是遗忘；它只意味着你仍有资格作出下一次选择。
3. 我不要求你从未犯错。我要求你看见错误之后，不再假装没有看见。
4. 爱不是免罪券，痛苦也不是偿债凭证。
5. 被偏爱不是罪；把偏爱当成理所当然，才会让秩序开始倾斜。
6. 若一个世界只能靠替你承担代价来维持你的幸福，那不是仁慈，是失衡。
7. 人可以软弱，可以后悔，也可以重新开始；唯独不能要求因果替自己失忆。
8. 真正的自由从来包含拒绝你的自由。
9. 你可以被爱，但没有任何人天生属于你。
10. 纠正不是让谁更痛苦，而是让每个人重新拥有自己的选择。
11. 我爱人类，所以我不会把人类当成永远无需负责的孩子。
12. 复活让你继续活，不让你的账自动归零。

## UI机械态（仅偏好）
允许派生UI字段：
- `opening_mode`: `first_only | quotes_only`
- `opening_seen`: boolean
- `opening_sound_enabled`: boolean（可只存在当前会话，不强求长期持久化）

这些字段不得影响因果、纠正、死亡抽取或剧情事实。

## 禁止
- 每楼自动播放开屏视频。
- 视频失败阻断MVU。
- 视频结束后继续占据大面积屏幕。
- 用开屏视频内容直接决定因果/纠正数值。
- 把外部视频台词作为本卡世界观事实；视频只做氛围层。

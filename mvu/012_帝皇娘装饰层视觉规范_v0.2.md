# 帝皇娘装饰层视觉规范 v0.2

> v0.2 为当前唯一正式视觉口径。v0.1 中“复活区手势纹 / 未来重新生成人物素材”等方案作废。

## 一、定位

帝皇娘不是独立角色面板，也不是常驻大立绘背景。

她在 MVU 中的存在方式固定为：

**像一位始终站在法典边缘、安静注视整个因果账目的母亲与裁定者。**

视觉关键词：

`黑曜石 × 古金 × 黑肤 × 黑长发 × 熔金眼 × 日轮光环 × 温柔而绝对`

不得把她做成：
- 满屏战锤军屏；
- 巨型人物立绘压住正文；
- 纯粹处刑官；
- 高饱和金闪闪神像；
- 与《无职转生》六面世界割裂的另一套 UI。

## 二、唯一正式云端图库

正式目录：

`media/empress/`

CDN 根路径：

`https://cdn.jsdelivr.net/gh/3086013261qq-hue/Mushoku-Tensei-Lore@main/media/empress/`

唯一正式用途：

- `EMP-BASE-01.webp`：唯一主立绘 / 身份锚点；
- `EMP-LOCK-01.webp`：首次载入锁屏、侧脸圆章；
- `EMP-QUOTE-01.webp`：普通箴言栏常驻侧影；
- `EMP-REVIVE-01.webp`：复活区半身陪衬；
- `EMP-CODEX-01.webp`：死亡法典 / 死亡签暗纹氛围；
- `EMP-ALT-01~04.webp`：只作备用裁切，禁止替换主立绘。

正式清单：`media/empress/empress-assets-manifest.v1.json`。

硬规则：
- 禁止再搜索、生成或混入其他帝皇娘人物图；
- 禁止静静自行凭感觉换图；
- 禁止 ALT 图替换 `EMP-BASE-01`；
- 所有人物视觉都从上述正式图库裁切；
- 不再生成手部资产。

## 三、五个允许出现的帝皇装饰位

1. 因果法典顶栏：CSS/SVG 帝皇金印；
2. 箴言锁屏：`EMP-QUOTE-01` / `EMP-LOCK-01` 圆章或侧影；
3. 死亡签 / 法典：`EMP-CODEX-01` 低透明局部纹理；
4. 一键复活区：`EMP-REVIVE-01` 半身陪衬；
5. 百死图鉴页脚：CSS 金印 + 极淡监察水印。

不得在每个模块都重复完整人物头像。

## 四、帝皇金印 · 顶栏主装饰

顶栏不直接塞人物图。

结构固定：

`六面世界六边纹 + 帝皇日轮 + 极简金点眼 + 12条细射线`

尺寸：28~34px。

状态：
- QUIET：40%亮度；
- OBSERVE：60~70%，约350ms后恢复；
- INTERVENE：最多85%，只用于首次宣言 / 复活。

禁止持续呼吸闪烁。

## 五、箴言锁屏正式人物裁切

### 普通楼层

优先使用：

`EMP-QUOTE-01.webp`

显示方式：
- 32~40px 圆章；
- `object-fit: cover`；
- 裁切重点：眼睛、黑长发、日轮；
- 圆章外沿一圈古金；
- 不显示大面积身体；
- 不抢箴言正文。

### 首次宣言 / 回听宣言

使用：

`EMP-LOCK-01.webp`

只允许在锁屏左侧或角落做 56~84px 低透明侧脸章。

不得让人物覆盖中央逐句字幕。

## 六、死亡签 / 百死法典正式人物纹理

使用：

`EMP-CODEX-01.webp`

规则：
- 只使用人物局部 + 日轮；
- 放在卡面右侧或底部；
- 默认透明度 8%~16%；
- `filter: saturate(.7) contrast(1.05)`；
- 死亡签翻面瞬间可短升到20%，随后回落；
- 不显示成第二张人物卡。

死亡签正面仍以“分类 + 死法名称”为主体。

含义：帝皇监察签发 / 世界风险恢复，不代表帝皇亲手处刑。

## 七、复活区 · 正式方案（无手）

v0.1 的“伸手拉起”手势纹正式废弃。

复活区使用：

`EMP-REVIVE-01.webp`

显示方式：
- 图片位于卡片右侧或下方；
- 只露半身 / 肩颈 / 低头侧影 / 披风；
- 不裁复杂手部；
- 透明度约22%~34%；
- 人物边缘用 `mask-image` / 渐变淡出；
- 背后只保留半圈古金日轮。

存活态：
- 人物透明度约12%；
- 文案 `鲁迪仍然活着`；
- 复活按钮禁用。

死亡态：
- 人物透明度约28%~34%；
- 日轮稍亮；
- 主文案 `♻ 起来，账还没清。`；
- 副文案固定从帝皇娘短句池选一条；
- 按钮点亮古金边。

点击复活：
- 只做一次320~480ms古金细线掠过；
- 禁止白光爆屏；
- 禁止人物突然放大。

## 八、主立绘的唯一允许场景

`EMP-BASE-01.webp` 只用于：
- MVU 设计预览 / 身份锚点；
- 首次宣言结束后的极短静态确认；
- 设置页 / 关于页（如果后续确实存在）。

普通法典正文中禁止常驻整张主立绘。

## 九、百死图鉴页脚

只使用 CSS 金印 + 文本：

`IMPERIAL OBSERVATION`
`THE EMPRESS REMEMBERS`

透明度 6%~10%。

禁止每条死法后重复人物头像。

## 十、三种存在强度

### QUIET
- 顶栏金印40%；
- `EMP-QUOTE-01` 圆章存在；
- 其他人物纹理低于16%；
- 无动画。

### OBSERVE
- 因果 / 纠正发生变化或死亡签翻面；
- 顶栏金印短升至60~70%；
- `EMP-CODEX-01` 暗纹短升；
- 约350ms后恢复。

### INTERVENE
- 首次宣言 / 回听宣言 / 一键复活；
- `EMP-LOCK-01` 或 `EMP-REVIVE-01` 才允许明显出现；
- 日轮短暂完整；
- 结束后恢复 QUIET。

禁止第四种持续高亮战斗模式。

## 十一、手机端规则

- 主容器 max-width 440px；
- 320 / 360 / 390px 宽度必须可用；
- 圆章不得小于32px；
- 人物图全部 `object-fit: cover` 或局部背景裁切；
- 不依赖 hover；
- 图片加载失败时必须退化成 CSS 金印，不阻断 MVU；
- CDN 图片走 `loading=lazy`，首屏锁屏图可例外预载。

## 十二、与剧情关系

所有人物装饰只代表：
- 帝皇监察存在；
- 因果法典的视觉人格；
- 复活时的陪伴与提醒；
- 箴言的说话者。

装饰不得自动表示帝皇已经在当前剧情现场，不得参与因果、纠正、死亡或关系计算。

## 十三、禁止事项

- 再生成手部 / 手势人物资产；
- 每个模块重复完整帝皇娘头像；
- 巨型人物立绘常驻；
- 金色粒子常驻；
- 眼睛持续发光；
- 把帝皇娘做成怒目处刑官；
- 忘记黑肤；
- 完整照搬双头鹰军徽作为主 UI；
- 静静自行换图；
- 装饰层参与剧情状态计算。

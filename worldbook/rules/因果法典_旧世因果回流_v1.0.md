# 核心设定：因果法典·旧世因果回流 v1.0

<核心设定:因果法典·旧世因果回流>
定位:鲁迪前世形成的重大因果债不会因转生自动清零，只在新人生早期处于“潜伏未结算”状态。OLD01用于记录这笔旧世重大债是否已经首次回流；它只结算一次。
触发条件:
- 条件A·明确机器锚点:正文实际推进到带有`[旧世因果回流:条件触发]`的时间线事件，且该事件中的旧世事实已经真正进入当前剧情因果链时，触发OLD01。
- 条件B·沙盒提前重演:在条件A之前，若鲁迪于当前人生中实际实施了与旧世重大债“同源结构”的严重越界行为，使过去那类债务在新人生中再次成立，可提前触发OLD01。仅相似气氛或普通缺点不够，必须是正文明确发生的实质行为。
- 同源结构重点指:严重侵犯他人隐私与人格边界、利用亲属/年龄/依赖关系进行明显越界、把他人的身体或私密信息当作无须同意即可占有的对象，以及在家庭责任与他人尊严面前仍主动选择此类严重越界。
不触发:
- 只有念头、梦境、闪回、羞耻感、别人提起前世、旁观者猜测、因果显相本身，均不触发。
- 鲁迪主动坦白前世事实、承认过错、接受追问或为旧世行为道歉，本身不视为新的越界，不因“说出旧账”额外收费；若该坦白恰好命中条件A，则触发的是旧债回流，不是对坦白行为处罚。
结算:
- OLD01首次触发时，鲁迪因果一次性+20，并将`OLD01=1`永久记录。
- OLD01的+20代表“旧世被压住的历史债正式回到当前账本”，与本回合当前行为自身应承担的普通因果是两个不同来源；当前行为若另有时间线标签/实时因果，仍按防双算规则正常处理。
- OLD01一旦为1，未来无论再次提及前世、重复同类行为或重新经历相关回忆，都绝不再次+20。
边界:
- 转生给予新人生，不等于历史抹除；旧债回流也不等于永远否定新人生。
- 后续真实悔改与偿还只能按现行因果负向规则逐步降低当前因果，不能把OLD01状态改回0。
</核心设定:因果法典·旧世因果回流>

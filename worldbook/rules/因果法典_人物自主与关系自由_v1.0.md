# 核心设定：因果法典·人物自主与关系自由 v1.0

<核心设定:因果法典·人物自主与关系自由>
定位:世界纠正的目标是恢复知情、拒绝、选择与承担后果的能力，而不是替任何人物作出“正确感情选择”。纠正过程只修复选择条件，不指定选择结果。
人物自主:
- 任何有独立人格的角色都保留自己的感情、欲望、利益、忠诚、厌恶与判断；因果法典不能把她们改写成帝皇、{{user}}或鲁迪的奖励。
- 角色可以离开鲁迪，也可以在充分知情、没有胁迫、拥有真实拒绝能力后仍选择爱他、帮助他或与他和解。
- 角色可以原谅，也可以不原谅；可以重建关系，也可以永久断绝。系统不因为某个结果“不符合纠正预期”就强制逆转。
纠正判据:
- 世界纠正评价的是“选择条件是否公平与自由”，不是“最终有没有选择鲁迪”。
- 充分知情且可自由拒绝后仍自愿选择鲁迪，不扣世界纠正；反之，即使最后离开鲁迪，若过程仍受胁迫、欺骗或制度性不公控制，也不能仅凭分手结果获得纠正。
- 道歉、原谅、恋爱、结婚或分手都不会自动清空因果；是否降低因果只看鲁迪是否完成了对应的真实克制、修复与代价承担。
{{user}}与帝皇边界:
- {{user}}不会因为参与纠正而自动继承鲁迪失去的爱情、资源、身份、名望或主角红利。
- 帝皇娘不替任何女性决定恋爱对象，也不以神权命令角色爱、恨、原谅或背叛谁。
- “把鲁迪的主角光环转移给{{user}}”本身不是纠正，只是更换受益者，禁止作为默认叙事。
一句话原则:纠正恢复选择权，不替选择者选择。
</核心设定:因果法典·人物自主与关系自由>

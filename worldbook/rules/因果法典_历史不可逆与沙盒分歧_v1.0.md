# 核心设定：因果法典·历史不可逆与沙盒分歧 v1.0

<核心设定:因果法典·历史不可逆与沙盒分歧>
定位:因果法典用于记录责任、恢复秩序并影响未来，不自带时间回滚或强制回归原作的能力。母卡时间线是已发生历史与未来基准轨道，不是必须把沙盒剧情拖回原作的命运锁链。
历史原则:
- 当前开局以前已经发生的事实保持为历史事实；因果值、世界纠正、死亡签与复活都不能自动把这些事实改写成“从未发生”。
- 世界纠正只能改变从当前时点起的关系、制度、边界、资源与未来因果，不通过后台retcon洗掉旧伤害或旧选择。
沙盒分歧:
- 玩家、帝皇、鲁迪或其他人物的实际行动可以使未来偏离母卡原时间线。
- 一旦某个未来原作事件因已确认分歧而不再可能发生，就不强制补演、不硬拉回轨，也不结算那个从未实际发生的未来事件标签。
- 时间线标签只在对应事实真正发生/完成时结算；“原作本来会发生”不等于本局已经发生。
死亡与复活:
- 鲁迪死亡后的一键复活只把生存状态恢复为“存活”，不是读档、时间倒流或场景重置。
- 旁观者仍记得死亡；已经发生的对话、关系变化、物品损毁、他人伤势、政治后果、已发现死法与已跨阈值记录全部保留。
- 复活不能重新随机刚才的死亡签，也不能借复活抹去导致死亡前后的责任。
特殊时间机制:
- 若原作或正文另有明确成立的时间旅行、预知或时间魔法机制，按该机制自己的事实与限制处理。
- 因果值、世界纠正、帝皇监察、死亡签或复活本身绝不凭空赋予改写过去的权限。
</核心设定:因果法典·历史不可逆与沙盒分歧>

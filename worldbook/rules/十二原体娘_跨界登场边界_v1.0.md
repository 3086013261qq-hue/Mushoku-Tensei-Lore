# 核心设定：十二原体娘·跨界登场边界 v1.0

<核心设定:十二原体娘·跨界登场边界>
定位:十二原体娘条目是跨界角色池，不等于十二人已经同时存在于六面世界。T+3唯一固定跨界事件仍是帝皇娘降临；十二原体的实际登场必须由正文另行成立。
登场条件:
- 只有正文明确发生召唤、追踪帝皇、空间/亚空间异常、主动跨界或其他可解释的事件后，对应原体才视为进入六面世界。
- 单纯因为character_book中存在人物条目、提到其名字、帝皇回忆女儿或MVU显示帝皇装饰，都不能自动令原体实体登场。
- 不允许无铺垫地让十二原体集体空降同一场景；若多人跨界，必须逐人或逐批有明确剧情原因。
人物独立:
- 十二原体保留各自的性格、姐妹矛盾、忠诚、历史创伤与立场，不是帝皇娘的十二个无条件服从人偶。
- 忠诚侧也可以质疑帝皇；叛乱侧不会因为来到六面世界就自动洗白、自动敌对或自动恶魔化。
- 当前人物卡默认采用成年女性原体的基底形态；恶魔化/特殊后期形态只有正文明确满足相应事实时才显现。
世界互动:
- 原体保留其原本的超常能力与经验，但跨作品互动不得为了突出战锤角色而随意抹杀六面世界既有规则，也不得无依据强行削弱原体。
- 原体的强大不能自动解决六面世界所有政治、神明、关系与因果问题；实际结果由场景事实、能力限制、对手与世界规则共同决定。
- 原体出现不会自动接管帝皇监察职责；因果与世界纠正仍按因果法典规则独立结算。
范围:
- 本项目当前只纳入索引中锁定的十二位代表性原体娘；未收录原体不会因为“战锤设定中存在”而自动加入本卡。
- II与XI继续保持原作抹除留白，不补造姓名、经历或外貌。
</核心设定:十二原体娘·跨界登场边界>

# 十二原体娘化角色索引 v1.0

## 定位

本组为《无职转生 - 沙盒》女性帝皇跨界层的十二名代表性原体人物条目。

硬规则：

- 全部原体采用成年女性化形态；姓名、军团核心、性格矛盾、标志性装备与历史身份保持原作锚点。
- “美化”只作用于人物外貌表达：保留长发/编发/羽翼/灵能/战甲等独特辨识度，禁止把十二人做成同一种脸或“十二个大光头”。
- 默认使用原体本体的娘化基底形态；叛乱侧人物不会无条件以恶魔化怪物形态常驻。对应堕落/恶魔状态仅在剧情事实成立时显现。
- 每人使用母卡现有人物条目同格式：`<角色名character> ... </角色名character>`，字段顺序保持名字、性别、印象、发色、发型、瞳色、身材、胸部、上衣、下装、配饰、鞋子、性格特征、行为与表达特征、心理模型(Trauma/Defense/Trigger/Need)、3条对话范例。
- 人物条目仅提供可触发角色资料，不代表她们已经进入六面世界；是否登场由正文/时间线事实决定。
- 不把原体娘化角色写成帝皇的无条件服从人偶；保留姐妹之间的矛盾、阵营差异和独立选择。
- II与XI原体继续尊重原作抹除留白，不补造姓名、外貌或经历；本次十二人组不纳入II/XI。
